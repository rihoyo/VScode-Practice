편집기와 소스 제어

VS Code로 프로젝트 파일을 편집해. 왼쪽 소스 제어에서 PC에 설치된 Git을 조작하고 GitHub 저장소와 변경을 주고받을 수 있어.

다음 실습 · GitHub 저장소 복제

복제 완료 · VS Code 터미널에서 git --version을 확인했어. Git: 클론에서 GitHub 계정으로 로그인하고 저장소를 선택한 뒤, 상위 폴더로 문서\GitHub를 지정했어. 복제한 폴더를 열어 GitHub에서 편집했던 README.md도 확인했어.

  1. GitHub에서 vscode-practice 저장소를 열고 Code → HTTPS → 복사 아이콘을 눌러. VS Code에서 GitHub 계정으로 로그인해 목록에서 저장소를 고르는 방법도 있어.
  2. 확인 완료 · Git 설치 후 VS Code의 명령 검색에 Git: 클론 (Git: Clone)이 표시됐어. 검색할 때는 Ctrl + Shift + P를 눌러 git clone을 입력해.
  3. Git: 클론 (Git: Clone)을 선택해. 위에 보이는 Git: 복제(재귀)는 하위 저장소까지 복제할 때 쓰는 옵션이야. 복사한 HTTPS 주소를 붙여넣고 Enter. 로그인 화면이 뜨면 저장소를 만든 GitHub 계정으로 로그인해.
  4. 폴더 선택 창에서는 vscode-practice 폴더를 만들 상위 폴더를 골라. 완료 메시지가 뜨면 Open을 눌러. 왼쪽 파일 목록에 README.md가 보이면 연결 성공이야.

Clone은 GitHub의 파일을 PC로 가져오면서 연결 정보도 설정하는 기능이야. 이미 이 저장소를 복제한 폴더가 있다면 VS Code의 파일 → 폴더 열기로 그 폴더를 열어.

3. 이 페이지를 첫 커밋으로 올리기

대본으로 이해하는 커밋

  1. Windows 파일 탐색기에서 가이드의 HTML 4개와 guide.css, guide.js를 함께 복사해. 복제한 vscode-practice 폴더에서 README.md와 같은 위치에 붙여넣어.
  2. VS Code 왼쪽의 소스 제어(Source Control)를 눌러. 변경 사항(Changes)에 뜬 추가할 가이드 파일 옆 +를 눌러 이번 커밋에 넣을 파일로 골라.
  3. 메시지 칸에 VS Code 실습 기록 추가를 쓰고 커밋(Commit)을 눌러. 커밋은 변경 내역을 현재 PC에 기록해.
  4. Ctrl + Shift + P → Git: Push를 실행해. GitHub 저장소 페이지를 새로고침했을 때 가이드 파일 6개가 보이면 집에서도 받을 수 있어.
커밋이나 푸시에서 막히면

Git이 이름과 이메일을 요구하면 VS Code의 터미널 → 새 터미널에서 아래 두 줄의 예시를 자신의 값으로 바꿔 한 줄씩 실행한 뒤 커밋을 다시 눌러. 이메일은 GitHub 계정 설정에 표시되는 본인의 비공개 커밋 이메일을 써도 돼.

git config user.name "내 이름"
git config user.email "내 커밋 이메일"

GitHub에 새 변경분이 있어 푸시가 거절되면 Git: Pull로 먼저 가져와. 충돌이 표시되면 내용을 확인하고 해결한 뒤 푸시해. VS Code와 GitHub Desktop은 같은 Git 기록을 사용하므로, 충돌을 줄이는 습관은 작업 시작 전에 Pull, 작업을 마칠 때 Commit과 Push야.

다음 수업 · 두 AI에게 같은 파일 읽히기

VS Code에서 Ctrl + Shift + X로 확장 검색을 열어. @id:openai.chatgpt와 @id:anthropic.claude-code를 각각 검색하고, OpenAI와 Anthropic이 게시한 확장을 설치해. 각 채팅을 열어 로그인한 뒤 같은 저장소의 README.md를 읽혀봐.

두 AI가 공통 작업 규칙을 읽게 할 때는 AGENTS.md를 만들고 CLAUDE.md에 @AGENTS.md를 적어. Figma MCP와 워크트리는 이후 실습에서 다룰 항목이야.
