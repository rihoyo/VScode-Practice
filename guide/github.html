1. GitHub에서 시작 · 확인 완료

비공개 연습 저장소 vscode-practice를 만들고 GitHub 웹에서 README.md에 메모를 남기는 실습을 확인했어. 회사에서는 VS Code를 열어 둔 상태야.

Clone · Push · Pull

GitHub는 프로젝트 파일과 Git 커밋을 온라인에 보관해.

  • Clone은 저장소를 PC로 처음 복제해.
  • Push는 PC의 커밋을 GitHub에 올려.
  • Pull은 GitHub의 새 커밋을 받아 현재 브랜치에 반영해.

4. 집에서 열고 이어가기

집 PC의 VS Code에서는 처음 한 번 복제 단계대로 같은 저장소를 복제해. 이미 복제했다면 그 폴더를 열고 Git: Pull을 실행해. Windows 파일 탐색기에서 vscode-guide.html을 더블클릭하면 브라우저에서 이 페이지가 열려.

Ctrl + S는 파일 저장, Commit은 버전 기록, Push는 GitHub에 올리기, Pull은 GitHub의 변경 가져오기야.
