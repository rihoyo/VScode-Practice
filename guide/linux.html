리눅스란 무엇인가

리눅스는 운영체제의 핵심인 커널의 이름이다. 커널에 셸, 패키지 관리자, 기본 프로그램을 묶어 배포한 것이 배포판이고, Ubuntu, Debian, Red Hat 계열이 대표적이다. 서버와 클라우드 대부분이 리눅스 위에서 돌아가므로 네트워크 공부와 함께 잡아야 한다.

master@linux:~$ cat /etc/os-release   # 배포판 이름과 버전을 본다
master@linux:~$ uname -r              # 커널 버전을 본다

파일 시스템 구조

리눅스는 드라이브 문자 없이 최상위 / 하나에서 모든 경로가 시작된다.

/
├── home   사용자별 개인 폴더
├── etc    설정 파일
├── var    로그처럼 계속 변하는 데이터
├── usr    설치된 프로그램과 라이브러리
└── tmp    임시 파일

사용자와 권한

ls -l로 보이는 rwxr-xr--는 소유자, 그룹, 그 밖의 사용자가 읽기(r), 쓰기(w), 실행(x)을 할 수 있는지를 나타낸다. 숫자로는 r=4, w=2, x=1을 더한다. 아래 칸을 눌러 보면 숫자와 문자가 어떻게 바뀌는지 볼 수 있다.

r 읽기w 쓰기x 실행 소유자 그룹 그 밖 
master@linux:~$ chmod 644 파일이름
결과 표시 -rw-r--r--
PACKAGE~/linux/package

패키지와 서비스

  • Debian·Ubuntu 계열은 apt, Red Hat 계열은 dnf로 프로그램을 설치한다.
  • 서비스는 systemctl status 서비스이름으로 상태를 보고 start, stop, enable로 다룬다.
master@linux:~$ sudo apt install 프로그램이름
master@linux:~$ systemctl status 서비스이름
NETWORK~/linux/network

리눅스에서 보는 네트워크

주소와 서브넷의 원리는 네트워크의 주소 계산에서 다룬다. 여기서는 확인용 명령어만 익힌다.

master@linux:~$ ip addr        # 내 주소를 본다
master@linux:~$ ping 대상주소   # 연결을 확인한다
master@linux:~$ ss -tln        # 열린 포트를 본다
