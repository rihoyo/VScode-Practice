리눅스란 무엇인가

리눅스는 운영체제의 핵심인 커널의 이름이다. 커널에 셸, 패키지 관리자, 기본 프로그램을 묶어 배포한 것이 배포판이고, 계열은 패키지 형식과 관리 도구로 크게 갈린다. 서버와 클라우드 대부분이 리눅스 위에서 돌아가므로 네트워크 공부와 함께 잡아야 한다.

DEBIAN 계열Debian · Ubuntu · Linux Mint

패키지 형식은 .deb이고 apt와 dpkg로 관리한다. 입문용 데스크톱과 클라우드 서버에서 가장 흔하게 만난다.

RED HAT 계열RHEL · Rocky Linux · AlmaLinux · Fedora

패키지 형식은 .rpm이고 dnf와 rpm으로 관리한다. 기업 서버와 Red Hat 자격 시험 환경에서 쓴다.

master@linux:~$ cat /etc/os-release   # 배포판 이름과 버전을 본다
master@linux:~$ uname -r              # 커널 버전을 본다

파일 시스템 구조

리눅스는 드라이브 문자 없이 최상위 / 하나에서 모든 경로가 시작된다.

/
├── home   사용자별 개인 폴더
├── etc    설정 파일
├── var    로그처럼 계속 변하는 데이터
├── usr    설치된 프로그램과 라이브러리
└── tmp    임시 파일

계열마다 설정과 로그의 위치가 다르다. 설정에 따라 달라질 수 있으므로 기준으로만 삼는다.

사용자와 권한

ls -l로 보이는 rwxr-xr--는 소유자, 그룹, 그 밖의 사용자가 읽기(r), 쓰기(w), 실행(x)을 할 수 있는지를 나타낸다. 숫자로는 r=4, w=2, x=1을 더한다. 아래 칸을 눌러 보면 숫자와 문자가 어떻게 바뀌는지 볼 수 있다.

r 읽기w 쓰기x 실행 소유자 그룹 그 밖 
master@linux:~$ chmod 644 파일이름
결과 표시 -rw-r--r--

관리자 권한은 sudo로 빌려 쓴다. 관리자 그룹 이름은 계열마다 다르다.

Debian 계열은 sudo 그룹에 사용자를 넣는다.

Red Hat 계열은 wheel 그룹에 사용자를 넣는다.

master@ubuntu:~$ sudo aa-status   # AppArmor 상태를 본다 (Ubuntu)
master@rhel:~$ getenforce        # SELinux 모드를 본다
master@rhel:~$ ls -Z 파일이름   # 파일의 SELinux 라벨을 본다

패키지와 서비스

프로그램을 설치하는 도구가 계열을 가르는 가장 눈에 띄는 차이다. 서비스는 두 계열 모두 systemctl로 다룬다.

작업Debian · UbuntuRed Hat 계열
목록 갱신apt updatednf check-update
설치apt installdnf install
제거apt removednf remove
설치된 목록dpkg -lrpm -qa
 
master@ubuntu:~$ sudo apt update
master@ubuntu:~$ sudo apt install 프로그램이름
master@rhel:~$ sudo dnf install 프로그램이름
master@rhel:~$ rpm -qa | grep 프로그램이름
master@linux:~$ systemctl status 서비스이름   # start, stop, enable로 다룬다

리눅스에서 보는 네트워크

주소와 서브넷의 원리는 네트워크의 주소 계산에서 다룬다. 여기서는 확인용 명령어를 익힌다.

master@linux:~$ ip addr        # 내 주소를 본다
master@linux:~$ ping 대상주소   # 연결을 확인한다
master@linux:~$ ss -tln        # 열린 포트를 본다
master@ubuntu:~$ sudo ufw status          # 방화벽 상태 (Ubuntu)
master@ubuntu:~$ sudo netplan apply       # 네트워크 설정을 적용한다
master@rhel:~$ nmcli device status        # 네트워크 장치 상태를 본다
master@rhel:~$ sudo firewall-cmd --list-all  # 방화벽 규칙을 본다

따라하며 익히기

연습용 시뮬레이터다. 입력한 내용은 이 화면 안에서만 동작하고 어디에도 저장되지 않는다. 새로고침하면 파일과 진행 상태가 모두 처음으로 돌아간다. 실제 컴퓨터의 파일은 건드리지 않는다. 여기서 성공한 단계는 연습일 뿐이므로, 실제 환경에서 직접 확인한 뒤에만 완료로 표시한다.
