Clone · GitHub → 회사 PC
VS Code에서 복제를 누르면 Git이 GitHub 저장소의 파일과 이력을 가져와.
저장 → Commit → Push · 회사 PC → GitHub
VS Code로 파일을 저장해. Git으로 버전을 기록하고, 그 버전을 GitHub에 올려.
Pull · GitHub → 집 PC
집 PC에 이미 복제해 둔 저장소를 열고, GitHub의 새 커밋을 받아 이어서 작업해.

이후에 다룰 수업

  • Git · 변경 내용 비교, 브랜치로 실험하기, 충돌 읽기, 워크트리로 동시 작업하기
  • GitHub · 커밋 기록 찾기, 다른 PC에서 동기화하기, 변경 검토하기
  • VS Code · 프로젝트 폴더와 프로필, Codex·Claude 인계, Figma MCP 연결
이 기록을 직접 갱신하는 법

새 실습을 추가할 때는 제목과 함께 어느 도구에서 누르는지, 파일이 어디로 움직이는지, 성공하면 무엇이 보이는지를 기록해. 해당 도구의 목차에서 실습으로 링크하고, 확인한 단계만 완료로 표시해. 브라우저에서 새로고침해 본 뒤 커밋과 푸시를 하면 집에서도 갱신된 기록을 받을 수 있어.
