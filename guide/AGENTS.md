# guide 에이전트

「나의 개발 스텝」 홈페이지(`guide/`)와 Node.js 도구(`tools/`)를 맡아. 이 두 폴더 밖은 고치지 마.

- `guide/vscode-guide.html`에서 진행 상태를 확인해. 개념과 실습은 `git.html`, `github.html`, `vscode.html`에 기록하고, 다른 도구의 개념을 참조할 때는 해당 항목으로 링크해. 드롭다운(머리말 오른쪽 위, 스크롤하면 위쪽 고정 메뉴바 왼쪽)은 서로 다른 메인 페이지(VS Code 공부·리눅스·네트워크)로 이동하는 용도고, 개요·Git·GitHub·VS Code 같은 사이트 안 메뉴는 머리말 탭과 고정 메뉴바 탭에 둬. 현재 페이지 목차는 오른쪽에 둬.
- **설명문은 `~다.` 문체로 써.** 대화는 평소 말투를 유지하되 이 폴더 안의 문장과 지도 데이터는 `~다.`로 끝내. 같은 제목을 반복하지 말고 연속 항목은 `1.`, `2.` 번호로 구분해. 섹션에는 항상 `id`를 달아.
- 새 기술이나 연결을 배우면 `map-data.js`의 `NODES`와 `EDGES`에 추가해 개요의 기술 연결 지도에 반영해. 마스터가 확인한 연결만 `status: 'done'`으로 표시해.
- 고친 뒤에는 `tools` 폴더에서 `npm run check`를 실행해. 링크, 문체, 폰트, 지도 데이터, 에이전트 목록의 경로를 검사해 줘.
- VS Code 공부 세트의 디자인은 다크 모드 개발자 느낌이고, 모서리는 모든 페이지에서 각지게 해. 폰트는 고딕만 써. 바탕·명조 계열은 금지고, 모노스페이스 스택에도 한글 고딕 폴백을 넣어.
- 홈페이지는 서버 없이 브라우저에서 로컬 HTML로 열려야 해. 외부 라이브러리는 완성 파일을 `vendor/`에 커밋해 둬.
- **메인 페이지(사이트)는 색만이 아니라 레이아웃까지 새로 디자인해.** VS Code 공부 세트는 `guide.css`, 리눅스는 `linux.css`·`linux-viz.js`(근흑 바탕·인광 초록·모서리 괄호 패널·스캔 뷰포트), 네트워크는 `network.css`·`network-field.js`(전면 실시간 관계 그래프 위의 밝은 기술 문서)를 쓰고, 새 메인 페이지는 자기 CSS를 따로 만들어. 공용 메뉴 스타일은 `site-ui.css`가 맡고 색은 각 CSS의 변수로 정해.
- **등록**: 새 메인 페이지는 `site-nav.js`의 `SITES`에, 메인 페이지 안의 새 페이지는 해당 사이트의 `pages`에 추가해. 머리말에 `<div class="sitenav">`를 두고 목차에 `data-toc`와 링크별 `data-tags`를 달아. 그다음 `tools`에서 `npm run build`로 키워드 색인을 다시 만들어. 낡으면 `npm run check`가 알려 줘.
- 키워드 검색은 모든 사이트가 공유해(고정 메뉴바 오른쪽, `keywords.html`).
