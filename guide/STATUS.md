# guide 현황

- 목표: 「나의 개발 스텝」 홈페이지를 학습 기록이자 기술 연결 지도로 키운다.
- 관련 파일: `guide/*.html`, `guide/data/map-data.js`, `guide/assets/vscode/guide-map.js`, `guide/assets/vscode/guide.css`, `tools/check.js`
- 결정: 다크 모드, 각진 디자인, 고딕 폰트만 사용한다. 설명문은 `~다.` 문체다. 지도는 d3 물리 엔진을 쓰고 완성 파일을 `vendor/`에 커밋한다. 홈페이지는 저장소 전체를 공개(Public)하고 GitHub Pages의 `main`, `/ (root)`로 올린다.
- 확인 전: `npm-d3` 연결(진행 중), `vscode.html#claude-code` 설치 안내, `github.html#publish` 공개 절차(마스터가 공개 전환과 주소 접속을 아직 확인하지 못함).
- 다음 단계: 공개 주소로 접속이 확인되면 `github-pages` 연결을 `done`으로 바꾼다. 허브 구조를 지도에 노드로 추가하는 일은 `TASKS.md`를 따른다.
- 갱신: 2026-11-19 · 드롭다운을 메인 페이지 이동(VS Code 공부·리눅스·네트워크)으로 바로잡고, 개요·Git·GitHub·VS Code는 머리말·고정 메뉴바 탭으로 되돌렸다. 리눅스(터미널 창)와 네트워크(도면 문서)는 레이아웃부터 새로 디자인했다. 마스터 화면 확인 전.
- 다음 단계: 리눅스·네트워크 내용을 실습하며 채우고, 확인한 항목만 완료로 바꾼다. 지도(`data/map-data.js`)에 리눅스·네트워크 노드를 넣을지 정한다.

## 갱신: 2026-11-19 (레퍼런스 반영)
- 리눅스: 레퍼런스 영상 결(근흑·인광 초록·`[번호]` 라벨·모서리 괄호)로 재디자인. 파일시스템 스캔 뷰포트와 펼쳐지는 목차를 넣었다.
- 네트워크: 미드저니 홈 결로 재디자인. 화면 전체 실시간 관계 그래프, 사인파 숫자 격자, 마우스 인력, 실시간 지표를 넣었다.
- 마스터 화면 확인 전. 모바일 실기기와 스크롤 시 고정 메뉴바는 미확인이다.

## 갱신: 2026-11-19 (메뉴 정리)
- 고정 메뉴바가 리눅스·네트워크에서 안 나오던 문제를 고쳤다(스크롤 감지를 `site-nav.js`로 통합).
- 머리말: 드롭다운은 왼쪽, 오른쪽에 `# 태그 검색`과 `전체 키워드`. 직접 입력 검색은 고정 메뉴바에만 남겼다.
- 목차 칸의 검색 입력과 전체 키워드 링크를 없애고 그 페이지 태그 토글만 남겼다. 마스터 확인 전.

## 갱신: 2026-11-19 (키워드 검색 패널)
- 머리말 `# 태그 검색`을 `키워드 검색`으로 바꿨다. 누르면 입력칸과 이 페이지 태그·전체 태그가 나오고, 입력하면 관련 키워드와 섹션이 즉시 뜬다(방향키·Enter 지원). 고정 메뉴바 검색칸도 같은 패널을 쓴다. 마스터 확인 전.

## 갱신: 2026-11-19 (리눅스 계열 전환)
- 리눅스 페이지에 혼합·Debian·Red Hat 스위치를 추가했다(머리말과 고정 메뉴바). Debian은 Ubuntu 보라·주황, Red Hat은 붉은 계열, 혼합은 기존 초록이다.
- 내용도 계열별로 나눴다(apt/dnf, ufw/firewalld, AppArmor/SELinux, 자격 시험 등). 혼합 모드는 두 계열을 나란히 보여 준다.
- 전환 연출: Debian·Red Hat은 삭제 → 부팅 명령 → 글자·레이아웃 재구성(0.43초), 혼합은 글자 융합과 재배치(0.34초). 모션 줄이기 설정이면 즉시 바뀐다. 마스터 확인 전.

## 갱신: 2026-11-19 (용어 설명창)
- `glossary.js`에 용어 115개(발음, 풀네임, 직역, 뜻)를 등록하고 모든 페이지에 연결했다. 마우스 올림, 키보드 포커스, 터치 탭으로 설명창이 뜬다.
- 다음: 본문을 용어 중심으로 줄이는 작업은 페이지별로 진행한다(TASKS 후보). 마스터 확인 전.

## 갱신: 2026-11-19 (구조 정리)
- 설명창에 `undefined`가 뜨던 원인은 용어 5개(온프레미스, 서브넷, 방화벽, 라우팅, 스위칭)의 칸이 하나씩 빠져 있던 것이다. 고쳤고, 사전을 이름 붙은 필드의 JSON(`data/glossary/*.json`)으로 바꿔 빠진 칸은 `npm run check`가 막는다.
- `guide/`를 글(html), 코드(`assets/`), 데이터(`data/`) 층으로 나눴다. 사이트 목록은 `data/sites.js`로 뺐다. 구조 설명은 `AGENTS.md`의 "폴더 구조"에 있다. 마스터 확인 전.

## 갱신: 2026-11-19 (리눅스 따라하기 실습)
- 리눅스 페이지에 `[08] PRACTICE` 섹션을 추가했다. 연습용 가상 터미널에서 4개 실습(둘러보기, 파일·권한, 패키지·서비스, 네트워크)을 한 단계씩 따라 입력한다. Debian·Red Hat 스위치와 연동된다.
- 상태는 저장하지 않으며 새로고침하면 처음으로 돌아간다는 점을 섹션 맨 위에 적었다.
- `npm run check`가 모든 실습 단계를 두 계열에서 시뮬레이터로 실행해 검증한다. 마스터 확인 전, 실제 환경 확인은 아직이다.
