# guide 현황

- 목표: 「나의 개발 스텝」 홈페이지를 학습 기록이자 기술 연결 지도로 키운다.
- 관련 파일: `guide/*.html`, `guide/data/`(map-data.js, sites.js, ai-data.js, glossary/), `guide/assets/`(vscode, linux, network, ai, shared, home), `tools/`(build, check). 구조는 `AGENTS.md`.
- 결정: 다크 모드, 각진 디자인, 고딕 폰트만 사용한다. 설명문은 `~다.` 문체다. 지도는 d3를 `vendor/`에 커밋한다. 홈페이지는 저장소 전체를 공개(Public)하고 GitHub Pages `main`, `/ (root)`로 올린다.
- 기록 규칙: 새 변경은 아래 영역 줄을 고치고 "최근 변경" 맨 위에 한 줄만 더한다(5줄 넘으면 가장 오래된 것을 지운다). 같은 요청이 반복되면 새 줄이 아니라 기존 줄에 합친다. 마스터가 실제 화면에서 확인한 항목만 `[x]`로 바꾼다.

## 확인 전 (마스터가 실제 화면에서 보고 체크)

- [ ] 공개 주소 접속과 GitHub Pages 공개 절차(`github.html#publish`), 완료되면 지도의 `github-pages` 연결을 `done`으로
- [ ] `npm-d3` 연결(진행 중), `vscode.html#claude-code` 설치 안내
- [ ] 메인 페이지: 빨려드는 원형 연출(끊김 없음), 포인터 밖에서 자동 떠다님, 클릭 순간 연속성
- [ ] 마우스 포인터(크기, 테마 색, 호버·누름·드래그 범위·로딩 연출), 페이지 전환 코드 디졸브(0.31초/0.38초)
- [ ] 3d-test: 스크롤 감각, 구간 클릭 정면 보기, 목차 선 페이드, 끝 평면 페이지
- [ ] code-test: 계산 연출 속도감, 클릭/키 입력 타이핑, Enter 복귀
- [ ] 리눅스: Debian·Red Hat 전환 연출, 따라하기 실습, 리얼 연출(apt, dnf, ping)
- [ ] 네트워크 페이지 연출, 모바일 실기기, 스크롤 시 고정 메뉴바
- [ ] 메뉴 정리: 키워드 검색 패널, 목차 태그 토글, 용어 설명창(마우스·포커스·터치)
- [ ] `vscode.html` 6장: Ctrl+R 최근 폴더(마스터 기억 기반)
- [ ] `github.html`: 4-1~6-2장 메뉴 경로와 이름(Collaborators, Applications, Branches/Rulesets, 관리자 우회 항목, Archive), 무료 개인 계정의 비공개 저장소 브랜치 보호 조건, 조직 복구 가능 여부(공식 문서가 열리지 않음)
- [ ] `github.html`: 부 구분 목차 모양, clone 폴더 옮기기(1-3), 2-1 라이선스 안내(Fork·Template 버튼)
- [ ] `ai.html`: 슬래시 명령 이름, 시뮬레이터 6개 동작, 읽히지 않은 Codex 요금 칸(`?`), 상단 메뉴가 제목 위로 뜨는지, 3장 토큰 계산기(입력·예시·규칙 전환·조각 색), 7장 어디서 도느냐(환경 버튼 재생, 점 이동)·닿는 범위 표 호버·md 설계 그림, 2장 설치(운영체제 전환·복사 버튼, 실제 설치 명령 동작), 7장 기억 시뮬레이터(도구·상황 전환, 날아가는 연출, 파일 설명창)와 갈래 그림
- [ ] 목차를 누르면 바로 이동하는지, 목차의 주석이 6부와 따로 보이는지
- [ ] 주석 번호의 작은 위첨자 모양, 테마별 색, 마우스를 올렸을 때 설명창(제목 없음, 넓어진 감지 범위)

## 반영된 것 (영역별)

- 홈(`index.html`): 종이 바탕 코드 비 + ASCII 블랙홀, 포인터에 반응해 글자가 빨려 듦, 클릭하면 원형 소용돌이 후 선택 카드(4개). 포인터가 화면 밖이면 저절로 떠다님.
- 공용: 드롭다운(메인 페이지 이동) + 탭, 키워드 검색 패널, 마우스 포인터(cursor.js/css), 페이지 전환(transition.js), 용어 설명창(130개), 주석(번호+맨 끝 목록+설명창, check가 짝 검사).
- VS Code 공부 세트: 개요, Git, GitHub, VS Code(단축키 6장), 키워드, 연결 지도, 3d-test, code-test.
- GitHub 페이지(부-순서 번호, 제목은 한 줄): 1부 기본(1-1~1-3, 폴더 옮기기 포함) → 2부 남의 코드(2-1) → 3부 공개(3-1) → 4부 협업(4-1) → 5부 조직(5-1) → 6부 저장소 관리(6-1 소유권, 6-2 삭제) → 주석.
- 리눅스: Debian·Red Hat·혼합 전환, 계열별 내용, 따라하기 실습 4개(검증은 check가 두 계열에서 실행).
- 네트워크: 밝은 기술 문서 + 전면 관계 그래프.
- AI: 기초, 동작 방식, 실무, 컨텍스트, 기억(시뮬레이터), 하네스, 실습 6개, 플랜 비교(Claude, Codex), 업데이트(Claude Code 2.1.331, Codex CLI 0.172.0 기준, 2026-11-24), 출처.
