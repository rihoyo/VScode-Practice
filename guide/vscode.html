1. 편집기와 소스 제어

VS Code로 프로젝트 파일을 편집한다. 왼쪽 소스 제어에서 PC에 설치된 Git을 조작하고 GitHub 저장소와 변경을 주고받을 수 있다.

2. GitHub 저장소 복제

복제 완료 · VS Code 터미널에서 git --version을 확인했다. Git: 클론에서 GitHub 계정으로 로그인하고 저장소를 선택한 뒤, 상위 폴더로 문서\GitHub를 지정했다. 복제한 폴더를 열어 GitHub에서 편집했던 README.md도 확인했다.

  1. GitHub에서 vscode-practice 저장소를 열고 Code → HTTPS → 복사 아이콘을 누른다. VS Code에서 GitHub 계정으로 로그인해 목록에서 저장소를 고르는 방법도 있다.
  2. 확인 완료 · Git 설치 후 VS Code의 명령 검색에 Git: 클론 (Git: Clone)이 표시됐다. 검색할 때는 Ctrl + Shift + P를 누르고 git clone을 입력한다.
  3. Git: 클론 (Git: Clone)을 선택한다. 위에 보이는 Git: 복제(재귀)는 하위 저장소까지 복제할 때 쓰는 옵션이다. 복사한 HTTPS 주소를 붙여넣고 Enter를 누른다. 로그인 화면이 뜨면 저장소를 만든 GitHub 계정으로 로그인한다.
  4. 폴더 선택 창에서는 vscode-practice 폴더를 만들 상위 폴더를 고른다. 완료 메시지가 뜨면 Open을 누른다. 왼쪽 파일 목록에 README.md가 보이면 연결에 성공한 것이다.

Clone은 GitHub의 파일을 PC로 가져오면서 연결 정보도 설정하는 기능이다. 이미 이 저장소를 복제한 폴더가 있다면 VS Code의 파일 → 폴더 열기로 그 폴더를 연다.

3. 첫 커밋과 푸시

대본으로 이해하는 커밋

  1. Windows 파일 탐색기에서 최상단의 index.html과 guide 폴더를 함께 복사한다. 복제한 vscode-practice 폴더에서 README.md와 같은 위치에 붙여넣는다.
  2. VS Code 왼쪽의 소스 제어(Source Control)를 누른다. 변경 사항(Changes)에 뜬 추가할 가이드 파일 옆 +를 눌러 이번 커밋에 넣을 파일로 고른다.
  3. 메시지 칸에 VS Code 실습 기록 추가를 쓰고 커밋(Commit)을 누른다. 커밋은 변경 내역을 현재 PC에 기록한다.
  4. Ctrl + Shift + P를 누르고 Git: Push를 실행한다. GitHub 저장소 페이지를 새로고침했을 때 진입 파일과 guide 폴더가 보이면 집에서도 받을 수 있다.
커밋이나 푸시에서 막히면

Git이 이름과 이메일을 요구하면 VS Code의 터미널 → 새 터미널에서 아래 두 줄의 예시를 자신의 값으로 바꿔 한 줄씩 실행한 뒤 커밋을 다시 누른다. 이메일은 GitHub 계정 설정에 표시되는 본인의 비공개 커밋 이메일을 써도 된다.

git config user.name "내 이름"
git config user.email "내 커밋 이메일"

GitHub에 새 변경분이 있어 푸시가 거절되면 Git: Pull로 먼저 가져온다. 충돌이 표시되면 내용을 확인하고 해결한 뒤 푸시한다. VS Code와 GitHub Desktop은 같은 Git 기록을 사용하므로, 충돌을 줄이는 습관은 작업 시작 전에 Pull, 작업을 마칠 때 Commit과 Push다.

4. 두 AI에게 같은 파일 읽히기

VS Code에서 Ctrl + Shift + X로 확장 검색을 연다. @id:openai.chatgpt와 @id:anthropic.claude-code를 각각 검색하고, OpenAI와 Anthropic이 게시한 확장을 설치한다. 각 채팅을 열어 로그인한 뒤 같은 저장소의 README.md를 읽힌다.

두 AI가 공통 작업 규칙을 읽게 할 때는 AGENTS.md를 만들고 CLAUDE.md에 @AGENTS.md를 적는다. Figma MCP와 워크트리는 이후 실습에서 다룰 항목이다.

5. Claude Code 설치 방식

진행 중 · 아래 내용은 안내이며, 직접 확인한 단계가 아니다. 확인하면 완료로 바꾼다.

Claude Code는 확장(채팅창)과 터미널 명령(claude) 두 방식으로 쓸 수 있다. 두 방식의 능력은 같고 화면만 다르다. 대화 모델은 클라우드에서 동작하고, 파일 읽기와 수정은 이 PC에서 일어난다.

구분확장 (채팅창)터미널 (claude)
설치확장 설치 한 번명령어 설치가 따로 필요하다
화면버튼, 클릭, 변경 내용 미리보기글자만 표시된다
코드 전달편집기에서 선택하면 자동으로 전달된다파일 경로를 직접 적는다
적합한 경우처음 쓰는 사람, 변경을 눈으로 확인할 때명령어 연습, 가볍고 빠른 작업

터미널 설치 두 가지

PowerShell에서 아래 네이티브 설치 명령을 실행하면 Node.js 없이 설치된다.

irm https://claude.ai/install.ps1 | iex

Node.js를 설치한 상태라면 npm으로도 설치할 수 있다. 기술 연결 지도에서 Node.js와 Claude의 연결을 볼 수 있다.

npm install -g @anthropic-ai/claude-code

설치 후 터미널을 새로 열고 claude --version을 실행한다. 버전 숫자가 나오면 성공이다. 작업 폴더에서 claude를 입력하면 첫 실행 때 로그인 안내가 나온다.

6. 자주 쓰는 단축키

마우스로 메뉴를 찾는 시간을 줄이는 단축키를 모았다. 아래는 Windows 기준이고 Mac은 Ctrl 대신 Cmd를 쓰는 경우가 많다. 안 먹히는 단축키는 Ctrl + K 다음 Ctrl + S로 키보드 단축키 화면을 열어 확인한다.

자주 쓰는 폴더 빨리 열기

Ctrl + R을 누르면 최근에 연 폴더와 작업 영역 목록이 화면 위쪽에 뜬다(Open Recent). 목록은 최근에 연 순서로 보인다.

  1. Ctrl + R을 누른다.
  2. 폴더 이름 일부를 입력하면 목록이 걸러진다. 예) VScode
  3. 방향키로 고르고 Enter를 누른다. 지금 창이 그 폴더로 바뀐다. 성공하면 왼쪽 탐색기에 그 폴더의 파일이 보이고, 창 제목에 폴더 이름이 나온다.

같은 목록은 메뉴에서도 열린다. 왼쪽 위 파일(File) → 최근 항목 열기(Open Recent)를 누르면 되고, 이 메뉴 맨 아래의 Clear Recently Opened로 목록을 비울 수 있다. 목록은 이 컴퓨터의 VS Code에만 저장되므로 다른 PC에서는 보이지 않는다. 폴더를 옮기거나 지우면 목록의 그 항목은 열리지 않는다.

터미널에서 열고 싶으면 폴더 안에서 code .를 입력한다. 점(.)은 지금 폴더라는 뜻이다. code 문서\GitHub\VScode-Practice처럼 경로를 적어도 열린다. code 명령을 찾을 수 없다고 나오면 VS Code를 새로 설치할 때 PATH 추가 옵션을 켜지 않은 것이다.

확인 전 · Ctrl + R 최근 폴더 열기는 마스터의 기억을 바탕으로 적었다. 실제 화면에서 목록이 뜨는지 확인한 뒤 확인 완료로 바꾼다.
