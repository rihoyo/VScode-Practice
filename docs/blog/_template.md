# 글 제목 (핵심 키워드를 앞에)

> 한 줄 요약: 이 글을 읽으면 무엇을 할 수 있는지 한 문장으로 쓴다.

- 원문: `guide/파일.html#id` (블로그에는 싣지 않는다)
- 태그: VSCode, Git, 입문
- 카테고리: 개발 기초
- 작성 환경: Windows 11, VS Code, 기준일 YYYY-MM-DD

## 이 글에서 하는 일

무엇을 만들거나 설정하는지, 끝나면 어떤 모습이 되는지 2~3문장으로 쓴다.

## 준비물

- 필요한 프로그램 또는 계정
- 미리 알아 두면 좋은 용어: **용어** 는 한 줄로 설명한다.

## 1. 첫 번째 단계 제목

1. 누를 곳을 **굵게** 쓴다. 예: 왼쪽 **소스 제어**를 누른다.
2. 입력할 값은 `코드` 로 쓴다.
3. 성공하면 보이는 화면을 쓴다.

![첫 번째 단계 화면](01-first-step.png)

> 💡 참고할 점은 인용문으로 쓴다.

## 2. 두 번째 단계 제목

```bash
git --version
```

버전 숫자가 나오면 성공이다.

## 막혔을 때

| --- | --- | --- |
