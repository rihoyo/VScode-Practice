# 에이전트 목록

이 저장소 하나가 허브이고, 폴더 하나가 에이전트 하나다. 마스터가 `이름: 지시` 형식으로 말하면 총괄이 이 표에서 폴더와 규칙 파일을 찾는다.

| 이름 | 폴더 | 역할 | 규칙 파일 | 상태 |
| --- | --- | --- | --- | --- |
| guide | `guide/`, `tools/` | 「나의 개발 스텝」 홈페이지와 Node.js 도구 | `guide/AGENTS.md` | 운영 중 |
| blog | `docs/blog/` | 가이드를 티스토리용 마크다운으로 변환 | `docs/blog/README.md` | 요청 대기 |

## 새 에이전트 만들기

1. `projects/_template/` 폴더를 `projects/<이름>/`으로 복사한다. 기존 폴더를 에이전트로 등록할 때는 그 폴더에 세 파일을 복사한다.
2. `AGENTS.md`에 역할, 범위, 규칙을 쓴다. Claude가 읽도록 같은 폴더에 `CLAUDE.md`를 만들고 `@AGENTS.md` 한 줄을 적는다.
3. 위 표에 한 줄을 추가한다. 폴더와 규칙 파일의 경로는 `npm run check`가 실제로 있는지 검사한다.

## 폴더 안의 세 파일

| 파일 | 쓰는 사람 | 내용 |
| --- | --- | --- |
| `AGENTS.md` | 마스터와 총괄 | 역할, 범위, 규칙. 거의 바뀌지 않는다 |
| `STATUS.md` | 에이전트 | 목표, 관련 파일, 결정, 다음 단계. 총괄은 이것만 읽는다 |
| `TASKS.md` | 총괄이 추가, 에이전트가 완료 | 받은 지시와 완료 기준 |
